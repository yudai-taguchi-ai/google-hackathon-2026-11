# 使い方ごとの動き（オンライン・オフライン・Web・アプリ）

最終更新: 2026-11-09。アプリ・サーバー・資料・デモはこのルールに合わせる。

## 1. 4 つの使い方
| | Web（審査員が触る） | Android・通信あり | Android・通信なし |
|---|---|---|---|
| 警報 | サーバーが気象庁のフィードを見る（1 分使い回し）。大阪府（510）の大津波警報・津波警報・津波注意報だけを警報とする（訓練・取消・解除・若干の海面変動は除く）。デモの訓練電文の流し直しが優先 | 同じ（15 秒ごとにサーバーに聞く） | 前に受け取った到達予想時刻を使う |
| 始まり | 「揺れた（現在地）」か地点のボタン | 15 秒ごとに警報を確かめ、出ていれば自動で開始／「揺れた」ボタン | 「揺れた」ボタン |
| 避難先を選ぶ | サーバー（Routes API の道のり） | 端末ですぐ選ぶ → サーバーの答えが 2 分以上短ければ乗り換えて声で知らせる | 端末（OpenStreetMap の歩ける道のグラフで道に沿った距離。道から 250m 超離れている時だけ直線 × 1.6） |
| 選び直し | サーバー | サーバー（失敗したら端末） | 端末 |
| 到達時刻 | 下の「時刻の順番」 | 同じ | 同じ |
| 道案内 | 「Google マップで開く」 | Navigation SDK（目的地まで徒歩）＋矢印と距離 | 矢印と距離 |
| 会話 | 無し | Gemini Live（頼みごとは関数で受け、アプリが選び直す） | 端末の音声入力 → キーワードで聞き分け（分からなければボタン）。聞き分けのモデルは担当が作成中（docs/intent-model.md） |
| 声 | 無し | 読み上げ・ナビの声・Live。**Live 中は他を止める** | 読み上げ・保存した音声 |
| 言語 | 英語・日本語 | 画面と読み上げは英語（日本語の補足）。Live は相手の言語 | 同じ（Live 以外） |

## 2. ルール
1. **避難先は最初に出したものを守る**。サーバーの答えに乗り換えるのは、歩く時間が 2 分以上短い時だけ。乗り換えたら声で知らせる
2. **時刻の順番**: 気象庁の到達予想時刻（サーバーが受け取っている警報）＞ 端末が前に受け取った到達予想時刻 ＞ 「揺れた」を押した時刻＋26 分 ＞ 今＋26 分。端末でもサーバーでも同じ
3. **選び直しの計算は 1 か所**: 通信があればサーバー、無ければ端末
4. **声は 1 つずつ**: Gemini Live が話している間は、ナビの声・読み上げ・保存した音声を止める
5. **通信が戻ったら警報だけ取り直す**。避難先はルール 1 に従う
6. **Web は通信ありだけ**。審査員が流れを確かめる入口

## 3. 切り替わる時
| 切り替わり | 動き |
|---|---|
| 通信あり → なし | 「Switched to offline mode」と出す。Gemini Live は止める。Navigation SDK は保存した 15〜20 分の経路で続く見込み（O3 で確認）。矢印と距離は常に出ている |
| 通信なし → あり | 警報を取り直す（受け取れば到達時刻を更新）。避難先はルール 1 |

## 4. まだ無いもの（資料では「今後」と書く）
- 浸水の浅い道を Navigation SDK に経由地として渡すこと（今は目的地だけ。浅い道はサーバーが選んで返している）
- 端末の中の AI（FunctionGemma）での聞き分け（担当が学習中。docs/finetune-eval.md）
- 英語・日本語以外の画面
