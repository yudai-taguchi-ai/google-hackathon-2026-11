# 計画

> **最新の実装計画（担当・日程・API の約束）は [implementation-plan.md](implementation-plan.md)**。この文書の 4〜6 章より優先する（2026-11-09）。

最終更新: 2026-11-07

## 1. 何を作るか
津波警報が出たとき、旅行者（特に訪日客）が、いる場所から**市町村が決めた津波の避難先**へ、**母語の声で会話しながら**たどり着けるようにするアプリ。

- 警報は気象庁の発表をそのまま使う（アプリは警報を出さない）
- 避難先は市町村が決めたものを使う（アプリは避難先を決めない。決まっている中から、間に合う所を選んで案内する）
- 事前に、その地域の公式データと宿の避難経路を端末に準備しておく。Gemini 単体は災害が起きてから何も準備の無い状態で答えるので間違える（docs/background.md）

デモの舞台は**大阪湾沿岸（大阪市・堺市）**。国のデータに津波の避難場所が揃っており、訪日客の多い USJ・海遊館が海のそばにある。

## 2. 担当すること・しないこと
| 担当する | 担当しない |
|---|---|
| 警報が出てから避難先に着くまで、迷わず動けるようにする | 警報を出す（気象庁） |
| 市町村が決めた避難先を取ってきて、間に合う所を選び、道案内する | 避難先を決める（市町村） |
| 宿の中の避難経路（ドアの避難経路図）を手順にして案内する | 救助・避難所での生活 |
| 行き先の地域のデータを、旅行の前に最新にしておく | 全国のデータを毎日更新し続けること |

## 3. 構成
```
           ┌─ Web から開く（QR・リンク）─→ Z：自分たちの地図＋声の案内（Gemini Live）
旅行者 ────┤                                └→ Y：「Google マップで案内」ボタン（徒歩・経由地3か所まで）
           └─ Android アプリを入れる ───────→ X：Navigation SDK のアプリ内ナビ＋声の会話

共通のサーバー（Cloud Run）
  ① 気象庁の防災情報 XML を1分ごとに確認 → 津波警報を地域で絞って通知
  ② 避難先データ：国土地理院の指定緊急避難場所（津波に使えるもの）
     国のデータに無い市町村は、自治体の PDF を Gemini Argon で読み取って表にする（行き先ごと・更新日つきで共有）
  ③ 浸水想定区域：津波で水につかる範囲（国の公開データ）
  ④ 選ぶ処理：歩く時間（Routes API）と津波の到達予想時刻を比べ、間に合う高台 → 無理なら近くの避難ビル
     経路が浸水想定区域・川沿いを通ったら、経由地を足して引き直す
  ⑤ 説明：Gemini 3.8 Live が④の候補だけを使って母語で話す（候補に無い場所は口にしない）
  ⑥ 宿の避難経路図：旅行者が撮る → Gemini Argon で手順に → 端末に保存
```
- Gemini は「場所を選ぶ」ことをしない。名前・住所・位置はデータベースの値をそのまま出す
- 通信が混む時に備えて、避難先・経路・読み上げ音声を端末に先に保存しておく

## 7. デモの筋書き（案）
1. USJ の近くにいる旅行者（英語話者）。チェックイン時に宿のドアの避難経路図を撮ってある
2. 過去の津波警報を流し直す → 通知
3. アプリが「間に合う避難先」を選び、英語の声で説明。地図に経路
4. 「子どもが走れない」と話しかける → 近くの避難ビルに切り替え
5. Gemini 単体に同じ質問をした答えと並べ、公式データで採点した結果を見せる
6. 堺市で実際に歩いて案内させた映像

## 8. 評価（Gemini 単体との比較）
- 場所：大阪市の海沿いの区と堺市の約 30 地点（観光地＋海沿い）
- 比べる相手：Gemini Argon・3.8 Flash（API。Google 検索・Maps で裏付ける機能を付ける）、Google マップの「マップに相談」（スマホで数地点）
- 正解データ：国土地理院の指定緊急避難場所（大阪市 2026-09-11 更新、堺市 2026-09-08 更新）
- 指標：①挙げた場所が公式の津波避難場所である割合 ②名前と位置が合っている割合 ③浸水想定区域の中を高台として案内した数 ④一番近い正しい避難先と比べた歩く時間の差 ⑤到達予想時刻までに着けるか

## 10. 今後の展望（今回は作らない）
- アプリを閉じている間も、圏外への備えを定期的に更新する（Android の WorkManager ＝ 閉じていても OS が決まった間隔で処理を動かす仕組み）。今はアプリを開いている間だけ、最新の警報と避難先を裏で用意している。宿に着いた時・Wi-Fi につながった時にも更新する
- スマホの中で動くモデル（Gemma など）との声の会話。端末内のモデルが速く正確になれば、通信が無くても会話できる
- 宿・観光施設が QR を置き、避難経路図を登録する形（アプリが広まってから）
- 津波以外の災害（洪水・土砂・火山）への拡大
- 全国の自治体への対応（行き先ごとに取りに行く方式で広げる）
