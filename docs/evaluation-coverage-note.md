# 評価データと危険ケースの補足

FunctionGemma の変換後評価は既定で `test.jsonl` 全件を使います。`--limit 400` で従来の最初の400件に限定できます。`--test-data` で別の検証ファイルも指定できます。既存の予測ファイルは上書きしません。

従来の「危ない間違い」（危険ケースを `other` または `reselect(normal)` にした割合）は、過去結果との比較とチームで決めた成功基準のため変更していません。これに加えて「危険ケースの全不一致」を参考値として報告します。これは危険ケースで関数名または引数が正解と一致しなかった割合で、解析失敗や別の危険ケースへの誤分類も含みます。すべての不一致が同じ程度に危険という意味ではなく、成功基準も未設定です。

従来の400件と現在の全3,280件の点数は分母と構成が違うため直接比較しません。追加分は英語・中国語・韓国語のみなので、全体値に加えて必ず言語別を示します。
