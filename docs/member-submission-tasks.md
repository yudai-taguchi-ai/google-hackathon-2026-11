|---|---|---|

### Web版の追加確認（通信失敗からの復帰）
- 計算中に通信が失敗したら、計算中のまま止まらずエラーと「Retry / 再試行」が出る。
- 通信を戻して再試行すると、同じ地点・歩行条件・言語・開始時刻で再計算できる。
- 警報取得失敗は「警報なし」と表示しない。訓練中にページを開き直しても訓練と表示する。
- 自動テストの実行方法: `backend/tests/web/README.md`。API応答を模擬したPC幅・スマホ幅のChromiumテストであり、実スマホや公開サーバーの確認結果とは区別する。

## 4. 人が書いたテスト用の文（50 件）
目的: 聞き分けモデルを、Gemini が作った文だけで測ると「Gemini の癖に合わせただけ」になる。人が実際に話した文で測る。

1. スマホのキーボードの**音声入力**で、実際に声に出して文字にする（言い間違い・聞き間違いもそのまま残す）
2. 言語は英語 30 件・日本語 10 件・中国語か韓国語を話せる人がいれば 10 件（いなければ英語で）
3. 頼みごとごとに 5 件前後（一覧は [intent-model.md](intent-model.md) の 1 章）。**慌てた言い方・短い言い方・文の途中で切れた言い方**も入れる
4. 1 行 = 1 件で、次の形の `test_human.jsonl` にする（Google ドライブの提出フォルダとは別の場所に置き、モデル担当と田口に渡す）
   ```
   {"text": "my kid cant run what do i do", "lang": "en", "name": "reselect", "args": {"mobility": "slow"}}
   {"text": "the bridge is closed", "lang": "en", "name": "road_blocked", "args": {}}
   {"text": "ありがとう", "lang": "ja", "name": "other", "args": {}}
   ```
5. **学習には使わない**（テスト専用）
