# 確かめないといけないこと

最終更新: 2026-11-07（V4・V5 済、V21〜V23 追加）

- **致命度**：高 = 駄目なら方式を変える必要がある／中 = 一部の機能が変わる／低 = 見せ方や細部
- 確かめたら「状態」と「結果」を書き換え、決まったことは docs/decisions.md にも書く
- 担当は話し合って埋める

## 確かめ方のメモ

### V1・V2・V10・V13（Navigation SDK）
docs/setup-android.md の「最初に作る検証アプリ」で試す。見ること:
- 移動手段を WALKING にし、経由地 3 か所＋目的地で `setDestinations` が通るか
- 各経由地で「到着」になり、`continueToNextDestination` で次へ進めるか
- わざと別の道へ歩いた時、引き直しの行き先がどこか（`RouteChangedListener` でログ）
- 機内モードで案内が続くか

### V4（浸水想定区域）
- 国土数値情報「津波浸水想定」（大阪府分）を探す。無ければ大阪府・大阪市・堺市の公開データ
- 見ること：形式（GeoJSON・Shapefile など）、利用条件、USJ・海遊館の周りが入っているか

### V5（到達予想時刻）
- 気象庁防災情報 XML の「津波警報・注意報・予報」「津波情報」の電文の中身（到達予想時刻・予想の高さ・予報区）
- 過去の電文（2025-07 のカムチャツカの津波警報など）をデモで流し直せるか
- フィード: https://www.data.jma.go.jp/developer/xml/feed/eqvol_l.xml

### V6（正解データ）
- 国土地理院: https://hinanmap.gsi.go.jp/hinanjocp/hinanbasho/koukaidate.html から大阪市（27100）・堺市（27140）の「指定緊急避難場所」をダウンロード
- 無作為に約 20 件を選び、各市の津波避難ビル・避難場所の一覧と、名前・住所・「津波に使えるか」を照らす

### V9（Gemini Live をブラウザから）
- API キーをブラウザに置かない。サーバーで短期トークンを発行してブラウザに渡す形を試す
- 日本語・英語で話して、返事までの時間を測る
- 関数呼び出しで「避難先を切り替える」を呼べるか

### V4・V5 の出典
- 国土数値情報 津波浸水想定（A40）: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A40-2024.html （大阪府 2023 年版: https://nlftp.mlit.go.jp/ksj/gml/data/A40/A40-23/A40-23_27_GML.zip ）
- 気象庁 防災情報 XML 技術資料（サンプル電文集・コード表）: https://xml.kishou.go.jp/tec_material.html
- 1m の津波の到達時間（大阪府 2013 年の想定。泉佐野市の資料経由）: https://www.city.izumisano.lg.jp/material/files/group/70/hosoku-cleaned.pdf
- 堺市 津波の想定: https://www.city.sakai.lg.jp/kurashi/bosai/kojo/tsunami/tsunami.html
- 大阪市の資料（1時間50分で 1m 超）: https://www.city.osaka.lg.jp/kikikanrishitsu/cmsfiles/contents/0000011/11873/R7_p7.pdf
