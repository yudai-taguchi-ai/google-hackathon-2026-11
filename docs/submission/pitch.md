## 1. 原稿
1. OIF Team A です。日本を訪れた旅行者が、津波から逃げられるようにするアプリを作りました。
2. 大きな地震のあと、津波は早ければ数分で来ます。土地を知らない旅行者は、どこへ逃げればよいか分かりません。市町村は津波の避難場所を決めていますが、日本語の一覧で、旅行者には届きにくいです。さらに能登半島地震では、最大 839 の携帯基地局が止まりました。
3. では、生成 AI に聞けばよいのか。大阪と堺の 30 地点で Gemini に同じ質問をして、公式データで採点しました。場所はおおむね正しいのに、歩く時間を平均 6 分と答え、実際の道では 24 分かかりました。1 番目の場所が正しく、しかも間に合うのは 47% でした。
4. そこで、場所は AI に選ばせないことにしました。警報は気象庁、避難先は市町村のデータ、歩く時間は実際の道で計算します。AI は、説明と、話しかけられた頼みごとの聞き分けだけを受け持ちます。
5. （デモをご覧ください。…動画）
6. 通信がある時は、Cloud Run が気象庁の電文を確かめ、Routes API と Navigation SDK で道を案内し、Gemini Live と声で話せます。通信が切れても、旅行の前に保存したデータと、端末の中の道のつながりで、案内を続けます。
7. 圏外で話しかけた言葉は、端末の中の FunctionGemma が聞き分けます。追加学習で、正答率はキーワード方式の 70% から 93% になりました。
8. これから、全国の市町村に広げ、対応する端末ではカメラ越しに避難ビルの入口を示します。ありがとうございました。

- 数字の出典: 2・3 は docs/submission/product-doc.md の 3 章・7 章、7 は 6 章（テスト 400 件・変換後 93.25%）
- 「早ければ数分」は大阪府の想定ではなく一般論。聞かれたら「大阪湾は想定で最短 26 分前後、震源が近いと数分」と答える【要確認: 一次資料】
