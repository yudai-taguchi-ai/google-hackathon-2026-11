# 圏外の「聞き分け」モデル（担当向けのコンテキスト）

最終更新: 2026-11-09。やり方は担当が自由に決めてよい。このファイルは「何のために・今どうなっていて・何があれば組み込めるか」をまとめたもの。

## 1. 何を解きたいか
通信が無い時（圏外・機内モード）、旅行者が慌てて話した一言を、アプリの「頼みごと」に聞き分ける。

```
声 → 端末の音声入力（Android 標準・圏外でも動く）→ 文字
   → 【ここを作る】文字 → 頼みごとの id
   → アプリが公式データで避難先を選び直す・決まった文と音声で答える
```

- **避難先・道・時間はモデルに決めさせない**。モデルの仕事は「どの頼みごとか」だけ（決まりは docs/modes.md・docs/decisions.md）
- 分からない時は `other` を返せばよい。アプリは画面のボタンに回す（ボタンに回すのは安全な失敗）

### 頼みごとの id（アプリと同じ文字列）
| id | 意味 |
|---|---|
| reselect_slow | 速く歩けない（子ども・高齢者・けが・妊娠・荷物） |
| reselect_wheelchair | 車いす・ベビーカー・階段が使えない |
| reselect | 別の避難先にしたい（理由なし・混んでいる） |
| road_blocked | 道がふさがっている・通れない |
| ask_floor | 何階まで上がるか |
| lost_family | 家族・連れとはぐれた |
| injured | けがをした・具合が悪い |
| when_to_return | いつ戻っていいか |
| repeat | もう一度言って |
| other | それ以外・分からない |

学習データの `name`／`args` との対応: `reselect` + `mobility: slow` → `reselect_slow`、`wheelchair` → `reselect_wheelchair`、`normal` → `reselect`。

## 3. 方式の候補（どれでもよい・組み合わせてもよい）
| 方式 | 合いそうな所 | 気になる所 |
|---|---|---|
| 多言語 BERT 系の分類（mBERT・DistilmBERT・多言語 MiniLM など） | 決まった 10 種類から選ぶ仕事にそのまま合う。確率が出るので、低い時に `other` へ回せる。速い | 文を ID に切る部品（トークナイザ）を端末でも同じにする必要がある。辞書が大きい（25 万語前後）ので、大きさに注意 |
| FunctionGemma 270M（追加学習） | 引数を取り出せる（将来「〇〇橋が通れない」から場所を取るなど） | 文章を作るので遅め。形が崩れることがある。変換（.litertlm）が新しい手順 |
| ルール（キーワード） | 速い・軽い・中身が見える | 言い方が変わると外れる（70.5%） |
| 組み合わせ | 例: ルールで確かな物だけ先に拾い、残りをモデル | 作る手間 |

選んだ理由と比べた結果は、提出ドキュメントの「Google 技術を選んだ理由」「AI をどう使ったか」にそのまま使う。Google 製のモデル（mBERT・FunctionGemma・EmbeddingGemma など）だと説明しやすいが、必須ではない。

## 4. 物差しについて
- テスト 400 件は学習に使わない。比べる時は同じテストと score.py で測る
- 「ボタンに回す（`other`）」と「違う行動をしてしまう」は重さが違う。確率でボタンに回す方式を使うなら、**答えた割合**と**答えた時の正答率**も出すとよい（score.py に足してよい）
- 端末での速さ（ミリ秒）と大きさ（MB）も測る

## 5. アプリに組み込むために（形は相談して決める）
Claude Code（田口の側）が、渡されたものに合わせてアプリに組み込む。決め打ちはしないが、次があると早い。
- 端末で動く形のモデル（LiteRT の .tflite／.litertlm など）
- 文を ID に切る方法（辞書ファイル・設定）。学習の時と同じ切り方が再現できること
- 答えの並び順と id の対応
- `other` に回すしきい値（使うなら）
- **見本 20 文ほど**: 文・切った ID・答え・確率。端末側で同じ結果になるかの確認に使う

置き場所: リポジトリの `backend/finetune/` か Google ドライブ。100MB を超えるファイルは GitHub に入らないので、ドライブに置いて場所を知らせる（アプリはパックと一緒にダウンロードする形にできる）。
