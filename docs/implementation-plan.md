## 1. 全体の形
```
                ┌──────────── Cloud Run（backend/）────────────┐
                │ /api/alert  気象庁の電文（デモは訓練電文）       │
 Android アプリ ─┤ /api/plan   間に合う避難先＋浸水を避けた経由地  │
   │            │ /api/pack   行き先のデータ一式（オフライン用）   │
   │            └───────────────────────────────────────────┘
   │ 通信あり: Navigation SDK（徒歩・経由地）＋ Gemini Live（会話）

   │           モデルが無い・動かない時は「質問のボタン」
```

## 2. API の約束（最初に固定する。変えるときは全員に知らせる）
### POST /api/plan（今あるもの＋経由地）
- 入力: `{"lat": 34.65, "lon": 135.43, "slow": false, "lang": "en"}`
- 出力: 今の出力（decision・primary・alternatives・minutes_left・walk_speed_m_per_s）に `waypoints: [{lat, lon}]` を足す

### GET /api/alert
- 出力: `{"active": true, "kind": "大津波警報", "area_code": "510", "arrival_time": "2016-09-01T07:30:00+09:00", "is_training": true}`
- デモ用に `POST /api/alert/replay`（訓練電文を流し直す）

### GET /api/pack?area=osaka-bay&lang=en
- 出力:
```json
{
  "version": "2026-11-09",
  "area": "osaka-bay",
  "expires_at": "チェックアウトの日（過ぎたら端末から消す）",
  "shelters": [{"id": "...", "name": "...", "lat": 0, "lon": 0, "inundation_depth": "2.0〜3.0m", "floor_min": 3, "open_space": false}],
  "inundation": "簡略化した浸水想定（GeoJSON）",
  "arrival_default_min": 26,
  "answers": [{"id": "slow_walker", "text": "...", "audio_url": "..."}]
}
```
- 大きさの目標: モデルを除いて数十MB。モデルは別に、入れなくても使える
- `arrival_default_min` は §5 の N1（案）
- `answers` は §4 の頼みごとの一覧から作る

## 4. 圏外の会話：小さいモデルの追加学習
### モデルの選び方（端末に合わせて切り替える）
```
① Gemini Nano が入っている機種 → それを使う（ダウンロード不要）   … 今後の展望
② 余裕がある機種               → Gemma 4 E2B（約2.5GB）          … 今後の展望
③ それ以外                     → FunctionGemma（270M・数百MB）を追加学習したもの … 今回作る
④ どれも動かない・電池が少ない   → 質問のボタン                     … 今回作る
どれを使っても、選ぶのは「用意した答えの番号」なので、答えの中身は同じ
```

### 頼みごとの一覧（案。田口が確定する）
引数は 0〜1 個にする（引数が多いほど正答率が下がるという検証があるため）。
```
reselect(mobility = normal | slow | wheelchair)   子どもが走れない／車いす／足をけがした
ask_floor()                                      何階まで上がる？
road_blocked()                                   道がふさがっている → 別の避難先へ
lost_family()                                    家族とはぐれた
injured()                                        けがをした
when_to_return()                                 いつ戻っていい？
repeat()                                         もう一度言って
other()                                          どれにも当たらない
```

### 追加学習の手順
1. Gemini で、頼みごとごとに言い方を 100〜200 個作る（英語・中国語・韓国語・日本語など。慌てた言い方・短い言い方・音声の聞き間違い）→ 合計 1,000〜2,000 個
2. 学習とは別の言い方で、テスト用を 200 個ほど作る（覚え込むだけになるのを防ぐ）
3. Google Colab で学習（Hugging Face TRL。Google の Mobile Actions の手順に沿う）
4. 学習前と学習後の正答率を、言語ごとに表にする（提出ドキュメントの「AI をどう使ったか」に使う）
5. `.litertlm` に変換してアプリに入れる

### 時間と切り替え

| 学習データを作る | 1〜2 時間 | — |
